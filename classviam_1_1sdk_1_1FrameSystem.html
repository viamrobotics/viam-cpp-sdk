Detailed Description

The machine's frame system: the tree of reference frames viam-server builds from the frame config of every resource. Use it to find where a component is and to move poses and point clouds between frames.

viam-server owns one frame system per machine and publishes it under the reserved name $framesystem. A modular resource finds it in its Dependencies under that name, and RobotClient::resource_by_name hands it out under that name too. It is never listed in RobotClient::resource_names.
